# Private MCP registration context

The desktop host produces this descriptor only for the closed packaged launch shape it actually owns. It binds the selected root, actual protected Hearth home, exact compiled Hearth asset and fixed agent-only MCP arguments. It accepts no operator flag, token, environment, URL or arbitrary prefix. Source/default and foreign launch shapes return unavailable rather than inventing a command.

The descriptor travels only in the existing parent-native stdout handshake. It is absent from HTTP/renderer state. Its serialized UTF8 cap is2048bytes within the unchanged4096byte ready envelope. Native deserialization is optional for old hosts, and a malformed or foreign descriptor supplies no registration authority. Native validation binds root and command to the actual selected root and launched sidecar before retaining the private context with that owned host generation.

This producer opens or changes no client file and adds no renderer command. Conditional publication qualification, current-user native profile/defaults/overrides, private audit/original/receipt recovery and Settings controls remain required. Native/client/manual qualification is separate.
