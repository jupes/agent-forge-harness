# Native Chat usage by accepted turn

Each owned native Codex Chat turn retains its own saved usage view after a follow-up and reload. The two columns keep the native **latest response** and **thread total** scopes separate. Neither column is relabelled as a sum of the accepted application's turn.

The latest saved usage report for that accepted turn takes precedence. Its same-thread terminal report supplies a fallback when a separate usage report is unavailable. Missing fields stay **Not reported**; reported zero remains zero. Foreign bindings, obsolete versions and another accepted turn cannot supply the row's counters.

Requested model remains visible. The native transport does not identify the execution model, so observed model stays **Not reported**. Private journals and complete export retain the original events; the projection adds no transport, process, approval or follow-up authority.

Verification covers turn isolation, response/thread scope, terminal fallback, missing-versus-zero counters and model vocabulary. The actual inert app-server browser journey uses two supervised native turns, reload, keyboard submission and complete export; it checks that both historical/current tables retain their exact native reports without replay.
