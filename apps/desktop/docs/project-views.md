# Scoped project views

The project catalog and membership rules are in `project-contract.md`.
These views consume that contract; project ids are independent of names and
workspace paths never grant access by themselves.

## Producer

`projectSnapshotReader(home, deps)` in
`scripts/hearth/routes/project-summaries.ts` is shared by the home and Overview
routes. It bounds/coalesces the readonly export and reads only the served
workspace. `GET /projects/:id/overview` accepts a catalog id and no query
parameters. Unknown ids return 404. It returns `ProjectOverview` from
`types/project-overview.ts`, built by `buildProjectOverview(project, sources,
history)` in `scripts/projects/overview.ts`.

| View field | Source and limit | Interpretation |
| --- | --- | --- |
| Bead/queue counts, needs-you, epics | Normalized readonly tracker export; explicit epic ancestry AND project label | A missing epic or failed export prevents complete totals. Queue entries require backing metadata. |
| Sessions | Newest 500 workspace ledger summaries, joined through member beads | Observed metadata, not running/idle/permission state. The limit and failed reads remain explicit. |
| Forge runs | Existing run store of the served checkout | Only runs naming a member epic and no foreign checkout. Other worktrees are not searched. |
| File claims | Existing workspace ledger reservation fold, filtered to member beads | Unavailable reads stay unavailable. |
| Shifts | Newest 50 readable shift records, explicit workspace and member-epic binding | Unbound/unreadable records are not attributed. Process presence alone is not proof of a session accepting input. |
| Throughput | Newest 10,000 workspace events in 30 UTC days | Distinct recorded bead closures per day. External tracker changes are absent; a truncated read is marked partial. |
| Usage | Explicit member-bead `session.ended` events, last 7 days | Provider-reported fields only; duplicate session ends count once. Missing prices are absent, not zero. No allowance or subscription usage is inferred. |
| Keeper brief | Keeper producer | Unavailable until the standing Keeper publishes one; no synthetic summary is generated by these views. |

Each observation carries source, read time, completeness and reason. History or
session failures do not erase independently read tracker counts. No transcript
body is stored in or read from ledger metadata.

## Renderer and selection

`ProjectOverview` and `ProjectSessions` are keyed by project id and reject data
whose summary id differs. Reads are bounded through `useOperatorRead`, follow
the existing page stream and preserve labelled last-known values on failure.
Unmounted reads cannot replace another project's view. There is no timer poll
or second ledger stream.

`sessionRows(sessions, filters, asOf)` in
`apps/desktop/src/sessions-model.ts` is shared by the sidebar and full list.
It deduplicates ids by newest event, groups only the states actually supported
by the ledger (Observed, Ended today, Older), and nests same-group parent/child
relationships. Missing parents and cycles appear once without invented rows.
Filters cover actual provider, raw kind, bead, smith, reported state and search.
Unreported title, model, effort, branch and usage are displayed as unavailable.
Unknown providers retain their own name and an unknown monogram; they never
become Claude by default.

The session inspector requires a matching row in the selected project's scoped
summary. A foreign or missing session id produces an unavailable state. Bulk
selection remains read-only until the session-control producer supplies actual
eligibility and stop outcomes; the disabled control explains this. A row that
leaves the read result also leaves bulk selection.

| Navigation | Behavior |
| --- | --- |
| Open a project card | Stable project id, Overview destination, prior selection cleared |
| Project destination or object chip | Same project id; object selection carries its actual kind/id |
| Switch projects while a read is pending | Prior view unmounts; new scope starts without prior data |
| Browser Back | Restores the route's project and valid object selection |
| Global destination | Retains the current project context for returning |
| Unknown project id | Unavailable state; no guessed record or workspace scan |
| Archived project bookmark | Deterministic read of saved scope with an archived notice |
| Session selection | Opens the inspector; Escape/resize uses existing focus-return behavior |
| Minimum window | Collapsed sidebar keeps named, keyboard-reachable destinations and pinned Keeper |

Browser tests use the isolated real hearth, explicit tracker ancestry and
metadata-only ledger fixtures. Native smoke additionally seeds a private epic
and observed session, opens Overview, opens Sessions and verifies its inspector.
These automated checks do not constitute the owner's Windows human review.
