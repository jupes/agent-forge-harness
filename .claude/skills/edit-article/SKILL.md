# Edit an article

1. Read the whole draft and identify its audience, purpose, and requested edit scope.
   For a narrow copy edit, preserve the structure and edit directly.
2. For a structural revision, map each section's main point and the definitions or
   evidence it depends on. Keep the order when it already supports the argument.
   Present a proposed order when a consequential change needs the author's decision;
   use existing authorization when the user already requested a full restructure.
3. Revise section by section. Preserve claims, attribution, and uncertainty. Use
   short paragraphs where they help readability; the user's style takes precedence
   over an arbitrary character limit.
4. Check transitions, consistent terminology, and claims against the source draft.
   Flag factual gaps rather than filling them with invented evidence.
5. Return the revised article and explain substantive changes briefly. Edit a file
   when the request identifies it as the destination; otherwise return the text.

Complete when the requested sections are revised, the argument remains coherent,
and any material meaning changes or unresolved factual questions are visible.
